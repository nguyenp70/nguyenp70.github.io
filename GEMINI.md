# Project Instructions: nguyenp70.github.io

This file provides foundational mandates and conventions for Gemini CLI when working on this repository.

## Project Overview
A personal website hosted on GitHub Pages using a Jekyll-based static site generator and the `cayman` theme.

## Foundational Mandates
- **Static Site Logic**: Maintain the integrity of the Jekyll/GitHub Pages structure.
- **Security**: Never commit or log secrets, including any tokens stored in `.env`.
- **Environment**: All local operations should be performed within the WSL environment.

## Conventions & Style
- **Formatting**: Use clean, semantic Markdown.
- **Assets**: Organize any future images or assets in an `assets/` directory.
- **Theme**: Adhere to the `cayman` theme's layout and styling unless explicit customization is requested.

## Workflow
- **Validation**: Before suggesting content changes, ensure they are compatible with the Jekyll configuration in `_config.yml`.
- **Testing**: When applicable, use local previewing methods if the environment supports them.
